# 五代十国 · 乱世星图 🗡️✨

**零依赖 · 纯前端 Canvas 力导向知识图谱** —— 在「暗夜霓虹 × 国风赛博」的星图里，看五代十国 70 年乱世兴亡。

> 907 — 979 · 你方唱罢我登场 · 一部乱世生存指南

## ✨ 特性

- 🎨 **赛博国风视觉**：深空星云、流星、视差网格、节点呼吸光晕、关系边能量流动粒子
- ⏱ **时间轴播放器**（878–980）：拖动滑杆，看 14 个政权走马灯式登场与覆灭，节点出现伴随波纹特效
- 🕸️ **自研力导向布局引擎**：库仑斥力 + 边弹簧 + 碰撞分离 + 地理锚点，纯手写物理，无任何图库
- 🔍 **搜索定位** + 图例分类筛选 + 玻璃拟态详情卡片（国祚 / 都城 / 建立者 / 关联关系）
- 🏷️ **年轻化「梗标签」**：#儿皇帝 #黄袍加身2.0 #五代最强打工人 #词帝下线 #四年体验卡
- 🚫 **零依赖**：无框架、无 CDN、无构建，单个 HTML 文件离线即开即用

## 🚀 快速开始

方式一：直接双击用浏览器打开 `index.html`。

方式二：

```bash
python3 -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 🛠 技术实现

- **Canvas 2D + requestAnimationFrame**，DPR 自适应，60fps 渲染
- **自研力导向布局**：斥力场 + 边弹簧 + 碰撞分离 + 「故乡」地理锚点（松手自动回位）
- **时间轴驱动**：每个节点/关系带起止年份，随时间淡入淡出、激活关系
- **数据与渲染分离**：数据区以 `/*DATA-BEGIN*/ ... /*DATA-END*/` 标记，纯数据结构化定义，易于扩展
